Objetivo General

El propósito de este proyecto es desarrollar una aplicación web educativa que permita listar y registrar personajes de películas animadas

de Disney y DreamWorks, facilitando la comprensión de conceptos básicos de desarrollo web con FastAPI, SQLAlchemy y Jinja2.

Objetivos Específicos

  • Diseñar un modelo de datos eficiente para almacenar películas y personajes.
  • Implementar una API con FastAPI para gestionar la información.
  • Diseñar vistas HTML amigables que permitan a los usuarios registrar y visualizar datos fácilmente.
