Planeación del Proyecto

Objetivos

  • Listar películas de Disney y DreamWorks según personajes, género y estudio.
  • Permitir el registro, visualización y consultas de peliculas y personajes.

Fuente de Datos

  • FastAPI
  • SQLAlchemy - Documentación
  • Render - Despliegue
  • PostgreSQL - Base de datos
  • jinja2 - Documentación
  • Bulma - Framework
  • Font awesome - Iconos

Casos de Uso

  • Registrar una película.
  • Registrar un personaje.
  • Listar películas y personajes activos.
  • Filtrar personajes por película.
  • Filtrar personajes protagonistas.
  • Busqueda de peliculas por estudio.
  • Eliminación de personajes y peliculas.

Modelo de Datos

Se utiliza una base de datos con dos entidades principales: Película y Personaje, relacionadas entre sí.
